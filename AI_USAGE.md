# AI usage

I used AI as a development partner: to brainstorm, to improve ideas and existing code step by step, to write tests, and to explain.

| Tool | Used for |
|---|---|
| Claude Code | wrote the code, tests and measurements in this repo, from my expanded design; every edit approved by me |
| Claude (chat) | brainstorming, explanations, reviewing results against the assignment and the lectures |

## How the algorithm was built

- **The design.** The starting point was the pseudocode from the class. I expanded it into a fuller design, like a decision tree: what to do at each step, and what happens in the edge cases. The AI wrote the code from it.
- **The problems.** The AI found most of the problems in the first version. Some more came out of our brainstorming.
- **The order of work.** I preferred to start with a small, naive version and first reach the required minimum (correct output, at least 30 FPS). Only then did we improve the algorithm further, in small measured steps, until the current version.
- **Understanding.** Before moving on, I wanted to understand what each step does, why it happens, how, and why it was done this way and not another way.

## How I checked it

I checked that the images and the videos are valid and that all the output is correct.
